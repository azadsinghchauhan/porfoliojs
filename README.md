## ✦ Tech Stack

- **Core:** React 18, TypeScript, Vite
- **Styling:** Tailwind CSS, Custom Architectural Arches, Editorial Typography
- **Icons & Graphics:** Lucide React, HTML5 Canvas Agentic Graph
- **Telemetry:** Real-time client IP, geolocation, device category & session audit stream

---

## ✦ Getting Started

```bash
# Clone the repository
git clone https://github.com/azadsinghchauhan/porfoliojs.git

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
